# CorpOS Prototype — инструкции для агента

## Контекст проекта
Интерактивный прототип адаптивного интерфейса корпоративной ОС.
ВКР по теме: проектирование унифицированного интерфейса для сотрудников 
с разным уровнем цифровой грамотности.

## Дизайн-система
- Только @salutejs/plasma-web
- Никаких других UI-библиотек
- Все компоненты из plasma-web: Button, TextField, Card, Toast, Modal, Badge, Tabs, Switch, Checkbox, TextArea
- Цвета только через токены: не хардкодить hex-значения

## Архитектура
- UserModeContext: хранит текущий режим (basic | standard | expert)
- Режим доступен через хук useUserMode() в любом компоненте
- Переключатель режима — всегда в Header, доступен на всех экранах

## Три режима интерфейса
Это НЕ три разные системы. Это одна система с разным поведением.

**basic** — Базовый:
- Крупные элементы, явные подсказки под полями
- Пошаговые мастера вместо длинных форм
- Развёрнутые сообщения об ошибках с кнопкой действия
- Toast с полным объяснением результата

**standard** — Стандартный:
- Полная структура, подсказки по запросу
- Форма на одном экране
- Стандартные сообщения об ошибках

**expert** — Экспертный:
- Высокая плотность информации
- Кнопка «Пропустить» на онбординге
- Поиск как командная строка
- Краткий Toast вместо развёрнутых сообщений
- Минимум подтверждений

## Три ключевых сценария
1. Онбординг — первый вход, выбор режима, знакомство с интерфейсом
2. Глобальный поиск — поиск инструкции/документа, результаты, переход
3. Типовая задача — заявка на доступ к сервису, форма, ошибка, успех

## Правила кода
- TypeScript строгий, никаких any
- Каждый экран — отдельный файл в своей папке
- Мок-данные в src/data/, не inline в компонентах
- Роутинг через react-router-dom, с использованием BrowserRouter, Routes, Route и Navigate
- Стили только через styled-components с токенами Plasma
